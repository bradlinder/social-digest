Social Digest - Feature Roadmap & Release Status
==================================================

1. Admin Interface & Workflow Separation (Completed in v5.0.0)
---------------------------------------------------------------
[x] Tabbed Settings & Actions UI: Divided the WordPress admin screen into distinct tabs using standard WordPress `nav-tab-wrapper` (Settings, Editorial & Staging Queue, Actions & Diagnostics). This cleanly separates persistent configuration from operational triggers and diagnostic tests.

2. Editorial Workflow & Staging (Completed in v5.0.0)
------------------------------------------------------
[x] Digest Staging Queue: Interactive approval queue where draft digests can be reviewed before publishing.
[x] Custom Per-Item Commentary: Allows authors to attach custom notes, editorial takes, or takeaways directly above specific social cards.
[x] Per-Post Pinning & Ordering Rules: Allows editors to pin a specific high-impact social update to always appear as the lead story in the digest.
[x] Inline Excerpt Truncation & "Read More" Overrides: Set character fold limit on lengthy updates so one thread does not dominate the entire digest layout.

3. Media Optimization & WordPress Storage Hygiene (Completed in v5.0.0)
------------------------------------------------------------------------
[x] Modern Media Conversion: Automatically converts and compresses sideloaded images to modern formats (.webp / .avif) upon import to save server disk space.
[x] Local Asset & Avatar Caching: Caches remote profile avatars and social embeds locally in WordPress uploads to prevent broken embeds and link rot.
[x] Responsive Image / srcset Preservation: Generates standard WordPress responsive thumbnail sizes (medium, large, medium_large) for fast mobile rendering.

4. Newsletter & Syndication Distribution (Completed in v5.0.0)
---------------------------------------------------------------
[x] RSS-Only Digests: Option to publish digests exclusively to RSS feeds and newsletter campaigns (via `_social_digest_rss_only` meta filtering) without polluting the public homepage blog loop.

5. Admin Health & Diagnostics (Completed in v5.0.0)
----------------------------------------------------
[x] Dry-Run / Simulation Preview: "Simulate Next Run" test engine that inspects active feeds and calculates candidate posts, generated titles, harvested tags, and thumbnail selections non-destructively without modifying database records or timestamps.
[x] Network Connection Diagnostics: Real-time latency and HTTP status indicators for Bluesky and Mastodon API endpoints.

6. Version 5.1 Release Milestone (Completed in v5.1.0, v5.1.1, v5.1.2 & v5.1.3)
-------------------------------------------------------
[x] Duplicate Resolution Strategies: Configurable cross-posting resolution supporting "Prefer Mastodon if longer, otherwise Bluesky", "Longest text wins", and static network preferences. Compares clean text character lengths excluding hashtags and URLs.
[x] Strict Single-Post Exclusive Resolution (v5.1.2 & v5.1.3): Guarantees that when a duplicate is resolved, ONLY the winning platform's post is embedded in the WordPress post body; the secondary post is completely excluded.
[x] Multi-Signal Detection & Tag Harvesting (v5.1.3): Resolved cross-post detection for truncated posts and link cards via URL stem matching, prefix/substring containment, and relative text similarity. Intelligently harvests tags from the losing post to enrich WordPress taxonomy if the winning post lacks them.
[x] Real-Time Staging Workbench: Interactive editorial review workspace with inline commentary framing, priority reordering, and immediate early publish capability.
[x] Ephemeral Post Mockup Inspection: Interactive simulation inspector that renders full card mockups, tag taxonomy rankings, deduplication badges, and media selections on demand.
[x] Full WordPress 6.x UI Fidelity: Synchronized Admin Bar, settings tab navigation, and live published post preview across both Admin and Front-End views.
